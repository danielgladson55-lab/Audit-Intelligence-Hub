# Audit Intelligence Hub

Audit Intelligence Hub is an open-source professional portfolio project for technology risk, IT internal audit, cybersecurity governance and compliance.

## Version 1.0 capabilities

- Executive and operational dashboards
- Framework repository and control crosswalk
- Unified risks, controls, procedures, evidence and policy relationships
- Dynamic audit checklist generator
- Audit workspace, testing and findings register
- Evidence tracking
- Compliance and maturity assessments
- Policy and workpaper engine
- Microsoft 365, Azure, AWS and GitHub audit packs
- SAP, ServiceNow, Oracle, Salesforce and Workday audit packs
- Third-party risk and AI governance assessments
- CISA and CISSP knowledge centers

## Public demo limitation

Use synthetic information only. Version 1.0 stores data in the current browser using localStorage and does not provide authentication, a shared database or enterprise records management.

## Local or Codespaces development

```bash
npm install
npm run dev
```

## Production validation

```bash
npm run build
npm run preview
```

## GitHub Pages

The project is configured for the repository name `Audit-Intelligence-Hub`. In repository **Settings > Pages**, set the deployment source to **GitHub Actions**. Each push to `main` triggers the deployment workflow.
